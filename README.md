## Learning Path

A practical progression through this collection is:

1. **Start with Nmap** — identify accessible ports and services.
2. **Analyze banners** — use service information to understand the exposed attack surface.
3. **Explore SSH and FTP** — investigate common remote-access services and their security configurations.
4. **Practice Samba enumeration** — examine network file-sharing services and accessible resources.
5. **Study mail services** — learn how POP3, IMAP, and SMTP can be identified and investigated.
6. **Move to web reconnaissance** — map websites and identify application technologies.
7. **Practice WordPress fingerprinting** — understand how WordPress installations and components can be enumerated.
8. **Use WPScan concepts** — organize WordPress-focused reconnaissance within the authorized lab.
9. **Investigate user enumeration and backdoor clues** — connect individual findings into a broader CTF attack path.

## How to Use the Labs

1. Choose a challenge from the direct-link index.
2. Read the objective and confirm the authorized scope.
3. Begin with reconnaissance and service enumeration.
4. Record discovered ports, services, banners, technologies, and endpoints.
5. Analyze WordPress, mail, Samba, SSH, or FTP services when applicable.
6. Validate findings instead of assuming that every discovered item is vulnerable.
7. Test security weaknesses only against the provided lab environment.
8. Document the discovery process and security implications.
9. Review appropriate defensive controls after completing the challenge.
